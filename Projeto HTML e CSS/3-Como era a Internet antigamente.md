A Internet antigamente 

Ela era uma tela preta com letras verdes e protocolo básico para navegação se chama gopher, não tinha mouse era usado apenas o teclado que você utilizava. 
Em 1993 o Tim Berners-Lee criou o protocolo http://, linguagem HTML e www, mas nessa época o primeiro navegador foi o Mosaic que foi o primeiro compatível 
com o http:// criado por Marc Andreessen, graças esse conjunto o www se tornou realidade no mundo de hoje.
